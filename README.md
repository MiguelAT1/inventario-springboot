# Sistema de Inventario Web

Proyecto desarrollado con Spring Boot, Angular y PostgreSQL para la gestión de inventario.

## Funcionalidades actuales

- Login con JWT
- Control de roles (ADMIN y OBRERO)
- CRUD de productos
- Gestión de categorías
- Gestión de proveedores
- Movimientos de inventario
- Control de stock
- Persistencia en PostgreSQL
- Pruebas unitarias

## Tecnologías utilizadas

### Backend
- Java 21
- Spring Boot
- Spring Security
- JWT
- JPA / Hibernate

### Frontend
- Angular

### Base de Datos
- PostgreSQL

## Roles

### ADMIN
- Gestiona productos
- Gestiona movimientos
- Acceso completo

### OBRERO
- Gestiona productos
- Sin acceso a movimientos
